# РСЯ — размещение и откат

Базовая версия до подключения: `7b7126cbbb93c3e62a3346821ba90508b75faad0`.

- Один блок `R-A-20513421-1`, непосредственный потомок main после секции корзины, перед reviews.
- `shared/ads.js` загружается из head; async-загрузчик Яндекса добавляется в head один раз после отдельного согласия, срок выбора 180 дней. Отказ не блокирует заказ.
- Любая вложенная страница (включая iframe киоска) не запускает РСЯ, даже при сохранённом согласии. Страницы кухни не подключают ads.js.
- Форматы/платформы/максимальная высота в вызове render не ограничиваются. `disableGrab: true` отключает только сбор текстового контекста страницы с данными заказов. Не добавлены авторасстановка, отдельные overlay, fullscreen, floor/top ad.
- Нулевая резервируемая высота; отступы появляются только после успешной отрисовки содержимого. Ошибка/отсутствие предложения/таймаут очищают контейнер. Геометрия блока ограничена шириной main, высота содержимого не ограничена.
- Отзыв согласия сохраняется, блок удаляется; при наличии API запрашивается destroy. Уже выполненный сторонний код и ранее установленные cookies удалением блока отменить нельзя: вкладку следует закрыть/обновить после завершения заказа, cookies Яндекса удаляются в настройках браузера. Никакого автоматического обновления страницы с заказом нет.
- Политики обновлены; это описание реализации, а не юридическое заключение о полном соответствии оператора всем требованиям 152-ФЗ и закона о рекламе. Аккаунт/договор РСЯ, модерация, маркировка и отчётность по конкретной рекламе не проверены без доступа к кабинету Яндекса. Не обещать доход или фактический показ по одному лишь наличию кода.

## Быстро отключить рекламу

В новом коммите удалить только подключение `shared/ads.js` из head главной страницы. Пустой div не резервирует места; кухня/киоск/база не меняются. Сохранить политики как описание прежней обработки, уточнив дату отключения. Опубликовать через существующий main/root GitHub Pages.

## Полный откат пакета

Создать revert коммитов этого PR (для merge-коммита — `git revert -m 1 <merge_sha>`), проверить diff и опубликовать через main/root. Не применять reset/force push и не откатывать более поздние изменения сайта. SQL или восстановления базы не требуется. Уже открытым вкладкам нужна обычная повторная загрузка после завершения заказа.
