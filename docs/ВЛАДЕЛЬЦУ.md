# MissMaki Кухня: следующие действия с iPhone

**Пока создаём только отдельную тестовую базу. Реальные заказы не подключаем. PR №1 не объединяем. Сайт и фотографии сохранены.**

## 1. Где создать аккаунт?

Выбран первый кандидат для испытаний: **Татнет — российский управляемый Supabase**. Откройте в Safari [min.tatnet.ru](https://min.tatnet.ru/) → «Регистрация» / «Создать аккаунт». Не создавайте проект на supabase.com: это другое, зарубежное размещение.

## 2. Сколько стоит?

- Испытания: **0 ₽**, одна база Free. Только вымышленные данные.
- После успешных испытаний: Supabase **Pro — 1 490 ₽/месяц**, без отдельного VPS.
- Для размещения тех же файлов сайта тоже в РФ: Apps «Базовый» **499 ₽/месяц**, вместе **1 989 ₽/месяц** в пределах тарифов. Сейчас ничего переносить не нужно.
- Резервные копии именно этой услуги и возможные дополнительные расходы ещё уточняем. Окончательный счёт сверяется в кабинете до оплаты. Домен уже есть; новый покупать не нужно. Платный «свой домен Supabase» тоже не нужен.

Цены проверены 1 ноября 2026: [тарифы Татнет](https://tatnet.ru/pricing). Бесплатную базу не используем для рабочей кухни: у неё есть лимиты и пауза при простое.

## 3. Что нажать на iPhone сейчас?

Названия разделов приведены по публичной документации; проверка вашего кабинета и настоящего iPhone ещё не выполнена.

1. Safari → [min.tatnet.ru](https://min.tatnet.ru/) → зарегистрируйтесь. Если откроется страница входа, выберите регистрацию. Подтверждение почты/телефона выполните сами. Пароль сохраните в приложении «Пароли».
2. В кабинете откройте меню ☰ → **Supabase**. Не выбирайте конструктор T1000, покупку VPS или отдельный Managed PostgreSQL.
3. Нажмите **«Создать базу данных»**. Имя: **MissMaki-test**. Уровень: **Free**. Если есть выбор размещения — **Россия**; не выбирайте другую страну. Нажмите создание. Если Free недоступен, не оплачивайте Pro автоматически: сначала уточним причину.
4. Дождитесь готовности → откройте карточку базы → **«Открыть Studio»**. Данные входа Studio находятся в карточке; сохраните их в «Пароли». Не присылайте их в чат.
5. Studio → **Project Settings → API**. Передайте мне только **URL API** и **публичный anon key**. `service_role`, secret key, пароль Studio и пароль аккаунта не передавайте и в GitHub не вставляйте. Само получение двух публичных настроек ещё не даёт мне административного доступа к базе.
6. Отправьте в поддержку подготовленное [сообщение](СООБЩЕНИЕ-ПРОВАЙДЕРУ.md), чтобы подтвердить российское размещение, резервирование и нужный режим входа. Оно не содержит персональных данных покупателей.

Не вводите реальные имя, телефон и адрес покупателя в тестовую версию. Настройки missmaki.ru, DNS и GitHub Pages сейчас не трогайте.

## 4. Что я могу настроить самостоятельно?

Уже подготовлены панель, SQL, защита доступа, тесты и сборка отдельной тестовой копии под российский API. Большие фрагменты кода редактировать вам не нужно.

После появления тестового проекта и безопасного технического доступа смогу применить миграции, настроить тестовых сотрудников, интеграцию и провести реальные технические испытания в пределах предоставленных прав. Пока доступа к кабинету/Studio нет. Административный доступ передаётся через поддерживаемое безопасное подключение или отдельную временную учётную запись, если сервис это позволяет; не через публикацию паролей в чате. Если такого подключения нет, дам короткие действия для Studio с готовыми файлами без их редактирования.

Сначала данные вымышленные. Реальные заказы и дампы не выгружаем в ChatGPT или GitHub. Секреты не помещаем в публичный код.

## 5. Что обязательно сделать вам?

- Создать аккаунт на себя/ИП, подтвердить контакты и сохранить доступы.
- Получить ответы провайдера; после проверок согласовать тариф и оплату. За вас принимать платные условия я не буду.
- Проверить уведомление Роскомнадзора, сведения о месте базы и поручение обработки; при необходимости подать или обновить уведомление. Согласовать сроки хранения, доступы сотрудников и документы по ПД. Подпись и юридические решения остаются за вами; российский сервер сам по себе не закрывает все требования 152-ФЗ.
- На своих iPhone и планшете вместе со мной проверить вход, заказ, время, отказ, отзывы, звук и возврат интернета.
- Решение о запуске принимать после успешной приёмки. Пока нет проверки восстановления базы и необходимых функций, реальные заказы не включаем.

Подробное обоснование выбора и ограничения: [Российское размещение](РОССИЙСКОЕ-РАЗМЕЩЕНИЕ.md).
