# MissMaki Кухня: что нужно владельцу

Код подготовлен в отдельной ветке. **На missmaki.ru новая система пока не включена.** Рабочий сайт продолжает использовать прежнюю отправку. Пароли в GitHub не нужны.

## 1. Создать базу

1. На iPhone откройте Safari → [supabase.com/dashboard](https://supabase.com/dashboard) → Sign up / Sign in.
2. Нажмите New project. Назовите проект MissMaki. Пароль базы сохраните в приложении «Пароли»; никому не присылайте его.
3. Выберите регион и дождитесь готовности. До работы с реальными заказами согласуйте место хранения персональных данных с ответственным за их обработку. Публичное облако Supabase не предоставляет российский регион; для хранения в России нужен сервер Supabase в России или другой согласованный сервис. Код совместим с самостоятельным размещением Supabase, но его настройка здесь не выполнена.
4. Слева откройте SQL Editor → New query.
5. В GitHub откройте `supabase/migrations/001_kitchen.sql` → Raw → скопируйте весь текст → вставьте в SQL Editor → Run. Повторите с `002_catalog.sql`. Эти файлы вставляются целиком, редактировать их не нужно.
6. Authentication → Providers / Sign In → включите Anonymous Sign-ins. Это доступ покупателя только к собственным заказам, без регистрации.
7. Отключите обычную регистрацию по email (Allow new users to sign up). Сотрудников создавайте сами через Users. Anonymous Sign-ins должны остаться включены. Названия переключателей могут различаться между версиями панели.

## 2. Добавить себя и сотрудников

1. Authentication → Users → Add user → Create new user.
2. Укажите свою почту и придумайте пароль, включите Auto confirm user. Пароль сохраните в «Пароли».
3. SQL Editor → New query → вставьте короткую команду ниже. Замените только почту между кавычками на свою → Run:

```sql
insert into public.staff(user_id,role)
select id,'admin' from auth.users where email='ВАША_ПОЧТА';
```

4. Для сотрудника создайте другого пользователя и выполните ту же команду, заменив `admin` на `employee` и почту на его почту. Не выдавайте сотрудникам пароль от Supabase Dashboard.
5. Чтобы закрыть доступ сотруднику: SQL Editor → выполните команду ниже, подставив его почту:

```sql
delete from public.staff
where user_id in (select id from auth.users where email='ПОЧТА_СОТРУДНИКА');
```

## 3. Передать только публичные настройки

1. Project Settings → Data API / API: скопируйте Project URL.
2. API Keys: скопируйте **Publishable key** (`sb_publishable_…`) или старый **anon / public** key.
3. Передайте эти два значения исполнителю для подготовки тестовой версии. Это публичные настройки, не пароль. **Secret key, service_role, пароль базы и пароль сотрудника не передавайте и не вставляйте в GitHub.**
4. Если выбран свой сервер Supabase, сообщите его настоящий HTTPS-адрес. Для него исполнитель настроит конфигурацию отдельно.

## 4. Проверить на тестовой версии

Исполнитель должен дать две ссылки: тестовый магазин и его `/kitchen/`. Не оформляйте реальный заказ для первой проверки.

1. На планшете откройте кухню, войдите своей почтой и паролем.
2. Нажмите «Включить звук». Оставьте панель на экране.
3. На iPhone откройте тестовый магазин. Оформите небольшой тестовый заказ.
4. На кухне он должен появиться в «Новые». Нажмите «15 минут».
5. На iPhone дождитесь сообщения с номером заказа и 15 минутами без обновления страницы.
6. Вместе с исполнителем проверьте остальные времена, отказ, повторную отправку, потерю связи и отзывы по списку `ПРИЁМКА.md`.
7. Только после проверки исполнитель переключает основной сайт и отключает старый приём заказов. В Supabase должны остаться заказы, статусы и история.

## 5. Поставить кухню на главный экран

- iPhone / iPad: Safari → `/kitchen/` → «Поделиться» → «На экран Домой».
- Android: Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- Откройте значок «Кухня», войдите, нажмите «Включить звук».
- Держите устройство на зарядке, панель открытой, экран включённым. Если появилась надпись «Нет соединения», проверьте интернет. После возврата сети панель догрузит сохранённые заказы.
- Заблокированный экран и закрытая вкладка могут остановить звук. Фоновые push-уведомления здесь не подключены.

Отдельно настройте резервное копирование и срок хранения заказов с исполнителем. Бесплатный тариф Supabase и его приостановка не подходят для обещания непрерывной работы кухни.
