# Звонок MissMaki Кухня — 2 ноября 2026

Изменения только в текущей ветке `codex/missmaki-kitchen`, для существующего тестового приложения. SQL, новые базы, новые учётные записи и платные услуги для этого изменения не нужны. Рабочий missmaki.ru не переключается, PR не объединяется.

## Как работает

- После разрешённого пользователем включения звука первый полученный новый заказ запускает отчётливую серию тонов сразу. «Сразу» означает после получения записи через Realtime или резервную сверку, а не гарантированную доставку при выключенном интернете.
- Один общий звонок для всех новых заказов; повтор через 30 секунд от предыдущего начала. Новый заказ также вызывает немедленный сигнал, если предыдущая серия уже закончилась. Если серия ещё играет, звуки не накладываются.
- Только успешный серверный ответ на время/отказ убирает соответствующий заказ из звуковой очереди. Если остался другой новый заказ, общий звонок продолжается. Если ответ потерян, звонок продолжается до успешной сверки фактического статуса с сервером.
- Успешный ответ о принятии прекращает сигнал этого заказа даже при сбое последующего чтения списка. Запоздавший результат чтения, начатого до изменения статуса, не может заново включить его в очередь: используется версия локального обновления.
- Просмотр карточки, история, смена вкладки, чтение отзыва и обновление списка не подтверждают заказ и не отключают звонок. Кнопки «Остановить звонок» нет.
- Три разных синтезированных сигнала: «Кухонный звонок», «Двойной сигнал», «Тревожный перелив». Они создаются локально через Web Audio; загрузки аудиофайлов с внешних сайтов нет.
- Регулятор громкости 10–100%, начальное значение 90%. Это уровень приложения, а не системная громкость iPhone. Физическая громкость/беззвучный режим/выбранный Bluetooth-динамик остаются под контролем устройства.
- Сохраняются только выбор сигнала, громкость и предпочтение включить звук. Список заказов в localStorage не копируется. После перезагрузки очередь заново читается с сервера, и панель пытается возобновить звук; если браузер требует новый жест, показана кнопка «Включить звук».
- При временной потере сети известные новые заказы продолжают напоминать о себе, если браузер исполняет страницу. После восстановления сети очередь сверяется автоматически. О решении другого сотрудника во время отсутствия сети панель узнаёт только при восстановлении связи.
- Обновлены offline-shell/service worker и его версия. При загрузке без сети до первой сверки после перезагрузки статус заказов неизвестен: ложное восстановление очереди из непроверенных данных не выполняется.

## Ограничения устройств

Держите панель на экране, подключите планшет к питанию и настройте системную громкость. После блокировки/сворачивания iOS может приостановить Web Audio, WebSocket и таймеры. При возврате панель пробует возобновить звук; при запрете нужен повторный тап. Сохранённое предпочтение не является разрешением autoplay. Фоновые push не добавлялись. Слышимость в шумной кухне нужно проверить на реальном динамике; программно гарантировать её нельзя.

## Проверка владельцем на iPhone/iPad

1. Открыть только https://missmaki-site.tatnet.app/kitchen/ после обновления тестовой сборки, войти существующим сотрудником. Если настройки звука ещё не появились — перезагрузить вкладку при наличии сети. Настройки базы повторять не требуется.
2. Выбрать сигнал, установить громкость приложения и устройства → «Включить звук». Кнопка затем называется «Проверить звонок»; она не останавливает текущий сигнал.
3. Со второго устройства оформить вымышленный заказ «ТЕСТ — НЕ ГОТОВИТЬ». Услышать сигнал сразу после появления и через 30 секунд. Открыть историю/вкладку отзывов — напоминание должно продолжаться.
4. Создать второй вымышленный заказ. Принять первый любым временем: второй должен продолжать вызывать звонок. Отклонить второй: звонок прекращается. Повторить проверку всех восьми времён, только на тестовых заказах.
5. Отключить сеть при необработанном заказе: напоминание продолжается, отображается предупреждение связи. Вернуть сеть, принять заказ; затем перезагрузить страницу при другом новом заказе. Если телефон требует разрешение, снова нажать «Включить звук».
6. Свернуть/развернуть Safari и приложение с домашнего экрана. Проверить восстановление/подсказку о разрешении и фактическую слышимость. Не считать звук при заблокированном экране гарантированным.

## Технические проверки

`npm test`: **39 / 39 успешно**. Полный `npm run test:browser`: **48 / 48 успешно** в Chromium на размерах iPhone, iPad и компьютера. Тестовая сборка проходит.

Автоматические тесты проверяют интервал с управляемыми часами, отсутствие наложения и преждевременного отключения, несколько заказов, ошибку серверного подтверждения, успешное подтверждение с ошибкой последующего чтения, остановку после обработки последнего заказа, сохранение выбора/громкости, перезагрузку и восстановление связи. Отдельный браузерный сценарий использует настоящий Web Audio API; сценарии очереди используют явный тестовый транспорт и управляемую аудиомодель.

Это не запись испытания физического iPhone/Safari и не подтверждение реакции на настоящую staff-сессию Татнет. Новых заказов/пользователей в настоящей базе для разработки звука агент не создавал.
