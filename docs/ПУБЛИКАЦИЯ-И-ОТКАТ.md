# Публикация MissMaki

Владелец разрешил публикацию 4 ноября 2026. Используется существующий GitHub Pages: main, корень. Доступ к смене параметров Pages вернул HTTP 403; конфигурация хостинга не изменена. В корень применён проверенный candidate из MissMaki-final-ready-24a940c; целостность файлов сверена с манифестом перед копированием. База прежняя MissMaki-test, новые платные ресурсы не создаются.

Исходная рабочая версия остаётся в истории Git. Сборщик тестового сайта поддерживает повторную сборку уже включённой системы, не добавляя старый транспорт. Существующий CI продолжает проверять автоматические и браузерные сценарии.

## Аварийный режим

В сохранённом пакете MissMaki-final-unified.zip каталог safe-fallback содержит тот же сайт с остановкой новых отправок. При критической ошибке скопировать его содержимое в корень текущей ветки, проверить diff, commit/push и объединить в main. GitHub Pages опубликует его прежним способом. Уже сохранённые заказы доступны, меню/корзина остаются, данные не удаляются. Для восстановления обычной работы вернуть candidate. Не применять site-before.zip автоматически: он содержит старый транспорт Telegram/Google Apps Script.

На основном домене сотруднику нужно войти в кухню и включить звук: сессии и разрешения браузера между tatnet.app и missmaki.ru не переносятся. Полный Auth backup не заявлен, копии бизнес-данных остаются ручными.
