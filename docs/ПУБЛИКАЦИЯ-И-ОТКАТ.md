# Публикация MissMaki

Владелец разрешил публикацию 4 ноября 2026. Основной домен обслуживается существующим GitHub Pages. Исходники остаются в репозитории, а workflow Publish MissMaki собирает из них production candidate с публичными настройками существующей MissMaki-test. Служебные ключи не используются. Новые проекты, базы и платные ресурсы не создаются.

Перед публикацией выполняются автоматические и браузерные тесты, проверяются подтверждения установки 008, первой копии и разрешение владельца. Затем публикуется только candidate. Тестовая сборка остаётся отдельной. Для авторизации сотрудник использует тот же аккаунт, но на основном домене потребуется войти заново и разрешить звук; сессия и разрешение браузера с tatnet.app между доменами не переносятся.

## Аварийная остановка

GitHub → Actions → Publish MissMaki → Run workflow → ветка main → mode=safe-fallback → Run workflow. Этот режим останавливает новые отправки, сохраняет меню, корзину и обработку уже записанных заказов. Он не удаляет базу и не включает старый Telegram/Google Apps Script. Вернуть обычный режим — тот же workflow с mode=candidate.

Архив прежнего main сохранён в пакете как site-before.zip исключительно для сохранности. Его автоматическое восстановление вновь включило бы старый транспорт и не используется как первый способ отката. Зашифрованные копии базы сохраняются отдельно вручную. Файл сайта не является копией базы или Auth.
