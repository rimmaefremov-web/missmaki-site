# MissMaki

Существующий сайт доставки суши и роллов на GitHub Pages. Меню, фотографии и корзина сохранены.

В ветке `codex/missmaki-kitchen` подготовлена система «MissMaki Кухня» на Supabase. **Новая интеграция выключена до настройки и реальной приёмки. Первый кандидат для испытаний — Supabase в российском облаке Татнет; аккаунт на supabase.com создавать не нужно.**

Панель — `kitchen/index.html`, интеграция магазина — `shared/customer.js`, публичная конфигурация — `shared/config.js`. Пароли и служебные ключи не нужны в репозитории.

Для локальных проверок: `npm ci`, `npm test`, `npx playwright install chromium`, `npm run test:browser`.

Тестовый статический экспорт без изменения исходного сайта: `node scripts/build-russian-preview.mjs HTTPS_API_URL PUBLIC_ANON_KEY --output /tmp/missmaki-preview`. Адрес и ключ должны быть получены из реального **тестового** проекта. Команда не развёртывает инфраструктуру и не публикует сайт. Подробности — в инструкции развёртывания.
